欢迎来到麻将学习小游戏
Welcome to the Mahjong Learning Game

目标：组成 4 组有效组合 + 一对将牌
Goal: Form 4 valid sets + a pair. Each time you can only flip one face-down tile and discard one.

🎯 目标：
组成 4 组有效组合 + 一对将牌。每次只能翻一张隐藏牌，并打出一张无用牌。
Form 4 valid sets + a pair. You can only flip one hidden tile and must discard one useless tile each round.
📝 规则说明：
  • 每张牌最多出现 4 次 / Each tile can appear up to 4 times
  • 摸一张隐藏牌 → 必须打一张 → 总数保持 14 张 / Draw one face-down tile → Must discard one → Total remains 14 tiles
  • 成功完成后显示 🏆 奖杯 + 🎆 烟花动画 / Show trophy 🏆 and fireworks 🎆 after completion
  • 🚫 相同牌并排时只打一张，另一张保留 / If duplicates exist, discard only one and keep the other
  • 🃏 隐藏牌持续提供，直到游戏完成 / Face-down tiles continue until game ends
  • 🎴 已选有效组合满 14 张 → 胜利！/ Valid Sets with 14 tiles → Victory!
  • 👂 **听牌提示**：当你只差一张牌就能胡牌时，系统会告诉你听哪些牌。 / **Waiting Tile Hint**: When you are one tile away from winning, the system will tell you which tiles you are waiting for.

🎉 你赢了！恭喜！
You won! Congratulations!
